FAQ

Frequently asked questions

What does the LTM platform assess?

LTM continuously assesses two estates: your network firewall configuration (44+ hardening controls covering policies, routing, VPN, high availability, logging and administration) and your Microsoft Azure cloud security posture.

Which firewall and cloud environments do you support?

The platform is built around network firewall appliances and the Microsoft Azure cloud. It inspects firewall configuration state and Azure resources such as network security groups, subscriptions and identity exposure.

How does the AI copilot and the agents work?

Specialist agents connect to your firewall and Azure environments through secure endpoints. Ask questions in plain English and the AI returns data-driven answers with evidence and prioritized remediation guidance.

How does requesting a demo work?

Fill in the request form with a few details about your environment. A security engineer reviews it and contacts you to schedule a tailored walkthrough — no obligation.

How do I get an account?

Use the Create account option to register. New accounts are approved by an administrator before the first sign-in so access stays controlled.

Is my data stored securely?

Yes. Assessment history, conversations and reports are persisted in your own PostgreSQL database. Your firewall and cloud data is never shared with other tenants.
